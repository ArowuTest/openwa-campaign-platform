# 0.8.0 — Reporting and Operations

This milestone adds authoritative operational dashboards, governed incidents, delivery-exception reconciliation views, tamper-evident audit paging, campaign report snapshots and maker-checker controlled export requests.

## Security controls

- No plaintext MSISDN is returned by delivery-exception APIs.
- Export actions require recent MFA step-up.
- Export requester and approver must be different users.
- Approved export availability expires after 24 hours.
- Incident and export actions are recorded in the chained audit ledger.

## Known limitations

- Export file rendering and secure object-store download are not yet implemented.
- Live PostgreSQL migration and operational load validation remain required.
- Campaign report PDF and XLSX production remain part of the later reporting worker.
