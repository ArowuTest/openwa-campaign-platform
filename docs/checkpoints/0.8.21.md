# Checkpoint 0.8.21 — Campaign workspace governance

This checkpoint adds backend campaign-workspace controls that are deliberately separate from immutable campaign execution evidence:

- normalised internal tags with optimistic concurrency;
- append-only categorised notes for general, compliance, finance and technical teams;
- MFA-protected archive and restore actions for terminal campaigns;
- cancellation-impact assessment showing outstanding work, messages that cannot be recalled, and unknown outcomes requiring reconciliation;
- PostgreSQL persistence and append-only event evidence;
- OpenAPI and runtime wiring for memory and PostgreSQL modes.

Archiving does not delete campaign, recipient, delivery, consent, commercial or audit evidence. It changes operational visibility only. Live PostgreSQL execution remains an external validation gate.
