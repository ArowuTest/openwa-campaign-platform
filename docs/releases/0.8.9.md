# 0.8.9 — Material campaign change governance

This remediation release closes the approval-invalidation gap identified by the adversarial audit.

## Included

- Explicit material amendment workflow for audience, message, entitlement, transport and schedule changes.
- Automatic regression to the required campaign approval stage.
- Final approval invalidation for every material change.
- Commercial approval invalidation where message, audience or entitlement evidence changes.
- Authoritative message-version and audience-snapshot resolution at the HTTP boundary.
- Mandatory reason, recent MFA step-up and optimistic concurrency.
- Append-only material-change evidence with actor, changed fields, prior/new status and versions.
- Transactional PostgreSQL persistence for campaign update and event evidence.
- Correct persistence of schedule and maximum-recipient changes.
- OpenAPI coverage for amendment and evidence-history endpoints.

## Validation boundary

The code, domain tests, schema tests and contract checks pass. Migration 0041 still requires execution against a real PostgreSQL instance once a reproducible database driver and live test environment are available.
